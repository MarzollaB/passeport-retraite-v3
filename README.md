# Le Passeport de Patricia — version restaurée

Application React + Vite pour la fête de pension de Patricia.

## Démarrage

```bash
npm install
npm run dev
```

Mode test accéléré :

```text
?demo=1
```

Code équipage par défaut : `1608`.

## Supabase

1. Exécuter `supabase/schema.sql` dans le SQL Editor de Supabase.
2. Copier `.env.example` vers `.env`.
3. Renseigner `VITE_SUPABASE_URL` et `VITE_SUPABASE_ANON_KEY`.
4. Relancer Vite.
